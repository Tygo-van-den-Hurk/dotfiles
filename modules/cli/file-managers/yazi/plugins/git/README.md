## Overview

This is a plugin available on [nixpkgs](https://search.nixos.org/packages?query=yaziPlugins.git), for [yazi](https://github.com/yazi-rs) that integrates [Git](https://github.com/git/git) into it. Showing which files are modifies or added inline.
