## Overview

This is a plugin available on [nixpkgs](https://search.nixos.org/packages?query=yaziPlugins.git), for [yazi](https://github.com/yazi-rs) that integrates [sudo](https://en.wikipedia.org/wiki/Sudo) into it. Allowing commands to be run through sudo.
