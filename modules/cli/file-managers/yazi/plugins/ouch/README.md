## Overview

This is a plugin available on [nixpkgs](https://search.nixos.org/packages?query=yaziPlugins.git), for [yazi](https://github.com/yazi-rs) that integrates [Ouch](https://github.com/ouch-org/ouch) into it. Allowing for compressing and decompressing files, as well as viewing archives.
