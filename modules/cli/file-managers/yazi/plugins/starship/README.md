## Overview

This is a plugin available on [nixpkgs](https://search.nixos.org/packages?query=yaziPlugins.starship), for [yazi](https://github.com/yazi-rs) that integrates with [starship](https://github.com/starship/starship) into yazi. It's purpose is to show your starship prompt at the top instead of the current working directory.
