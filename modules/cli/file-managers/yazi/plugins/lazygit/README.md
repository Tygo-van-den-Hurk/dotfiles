## Overview

This is a plugin available on [nixpkgs](https://search.nixos.org/packages?query=yaziPlugins.lazygit), for [yazi](https://github.com/yazi-rs) that integrates [LazyGit](https://github.com/jesseduffield/lazygit) into it.
